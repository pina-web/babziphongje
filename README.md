# 홍제 한 끼 · 맛집 지도와 점심 룰렛

홍제동(홍제역·무악재·인왕시장·문화촌 인근) 식당 61곳을 실제 지도에서 둘러보고, 먹고 싶은 곳을 골라 점심 룰렛을 돌리는 단일 페이지 웹앱입니다.

## 기능
- **실제 지도 연동**: Leaflet + OpenStreetMap. 확대·이동, 가까운 핀 묶음 표시, 핀 팝업에서 바로 룰렛 후보 담기
- **길찾기 연결**: 식당마다 네이버지도 검색 · 카카오맵 길찾기 링크
- **거리 표시**: 홍제역 또는 📍 내 위치 기준 직선거리·도보 예상 시간, 가까운 순 정렬
- **좌표 없는 식당**: ‘지도에 위치 지정’으로 직접 핀을 찍어 저장
- **점심 룰렛**: 선택한 식당이 모두 같은 확률로 뽑히고, 결과가 지도에 바로 표시
- 검색·음식 종류 필터, 직접 식당 추가, 선택 내역 자동 저장(브라우저) 및 JSON 백업/복원

## 사용
`index.html` 하나로 동작합니다. GitHub Pages를 켜면 `https://pina-web.github.io/babziphongje/` 주소로 열 수 있어요.
(설정 → Pages → Branch: `main` / `(root)` → Save)
